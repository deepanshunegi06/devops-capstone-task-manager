# Security (Phase 9 - DevSecOps)

| Control | How it is implemented | File |
|---|---|---|
| **SonarQube code analysis** | `sonar-scanner` runs in Jenkins inside `withSonarQubeEnv('sonarqube')`; the pipeline stops if the **Quality Gate** fails (`waitForQualityGate abortPipeline: true`). Coverage, test and Bandit reports are imported. | `Jenkinsfile`, `sonar-project.properties`, `jenkins/docker-compose.yml` |
| **SAST** | Bandit fails the build on medium+ findings; flake8 lint | `Jenkinsfile` |
| **Secure Docker images** | multi-stage build (no compilers in runtime), `python:3.12-slim`, OS packages upgraded, **non-root UID 10001**, `HEALTHCHECK`, `.dockerignore`, OCI labels. Hadolint lints the Dockerfile; **Trivy** fails the build on CRITICAL CVEs and scans the K8s manifests. Compose runs the app `read_only`, `cap_drop: ALL`, `no-new-privileges`. | `Dockerfile`, `docker-compose.yml` |
| **Secret management** | No secret is committed. Compose reads `.env` (git-ignored; `env.example` is a template). Kubernetes uses a `Secret` created out-of-band (`scripts/create-k8s-secret.sh`) or encrypted with **Sealed Secrets** for GitOps. Ansible takes secrets from **ansible-vault** and uses `no_log`. Terraform writes the SSH key with `local_sensitive_file` (git-ignored). | `k8s/secret.example.yaml`, `ansible/group_vars/all/vault.yml.example` |
| **Secure credentials in Jenkins** | Docker Hub, GitHub, SonarQube, Slack and kubeconfig are Jenkins **credentials** (created by JCasC from environment variables) and only used through `withCredentials` / `withSonarQubeEnv`, so they are masked in logs. Docker login uses `--password-stdin`. | `jenkins/casc.yaml`, `Jenkinsfile` |
| **Role-Based Access Control** | *Kubernetes*: dedicated ServiceAccount for the app with **no API token**, a least-privilege `ci-deployer` Role for Jenkins, a read-only `developer` Role. *Jenkins*: role-strategy plugin - admins vs developers (build/read only). *ArgoCD*: AppProject restricts repo + namespace, with `read-only` and `release-manager` roles. | `k8s/rbac.yaml`, `jenkins/casc.yaml`, `argocd/project.yaml` |
| **Pod hardening** | `runAsNonRoot`, `readOnlyRootFilesystem`, `allowPrivilegeEscalation: false`, drop ALL capabilities, seccomp `RuntimeDefault`, resource limits, Pod Security Admission labels on the namespace | `k8s/app/deployment-*.yaml`, `k8s/namespace.yaml` |
| **Network security** | NetworkPolicies: only app pods reach PostgreSQL; app accepts traffic only from ingress / monitoring. AWS security groups expose admin ports only to `admin_cidr`; Jenkins webhook port only to GitHub's hook ranges. IMDSv2 + encrypted EBS on EC2. | `k8s/network-policies.yaml`, `terraform/modules/security` |
| **Application security** | PBKDF2-SHA256 password hashes, signed expiring API tokens, CSRF tokens on all forms, CSP / X-Frame-Options / nosniff headers, HttpOnly + SameSite cookies, per-user data isolation (tested), open-redirect protection (tested), `/metrics` blocked at Nginx | `taskmanager/` |
| **Detection** | Prometheus alert for brute-force logins; log analyzer flags repeated failed logins | `monitoring/prometheus/alert-rules.yml`, `scripts/log_analyzer.py` |
